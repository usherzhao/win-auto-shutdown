# Windows 定时关机助手 (WinAutoShutdown)

基于 **Go 语言** 与原生 Windows API 开发的轻量级定时关机小工具，专为 Windows 平台打造。支持**自定义提前提醒**、**一键延迟关机**、**开机自启动**以及**系统托盘静默守护**。

---

## 🌟 核心功能特性

### 1. 关机模式支持
- **指定时刻关机**：设定每天或当天的具体时刻（如 `23:30`）。若当前时刻已过，则自动顺延至次日；支持勾选“每天固定此时间关机”进行循环守护。
- **倒计时关机**：设定在特定时长后关机（如 `1小时30分钟`），提供 15分钟/30分钟/1小时/2小时/3小时 等快捷设定按钮。
- **强制关机防阻断指令**：执行关机时严格使用 `shutdown.exe -s -f -t 0`（重启使用 `shutdown.exe -r -f -t 0`），其中 `-f` 参数强制关闭所有应用程序，防止因未保存文件或卡死程序弹出对话框而打断关机；同时程序自身在发出指令后安全退出，确保绝不阻挡关机流程。
- **动作自由切换**：支持执行 **关机 (Shutdown)**、**重启 (Restart)** 或 **睡眠/休眠 (Sleep)**。

### 2. 关机前置顶提醒与音效
- **自定义提前提醒时间**：默认在关机前 **5 分钟** 进行弹窗提醒，用户可根据需要自由设置为 `1 ~ 120` 分钟（提供 3分钟、5分钟、10分钟 快捷按钮）。
- **置顶警报弹窗**：提醒窗口自动置顶并获取焦点（`HWND_TOPMOST`），配合 Windows 系统警报音（`MessageBeep`），防止用户在全屏游戏、观影或专注于工作时错过关机。
- **动态倒计时展示**：提醒窗口与主界面看板实时以秒级动态刷新剩余时间（如 `剩余时间: 04分58秒`），醒目警示用户及时保存工作内容。

### 3. 便捷延迟与取消选项
提醒弹窗与主界面、系统托盘中均提供丰富的控制操作：
- **🛑 取消关机**：立即终止当前定时关机任务，提示用户“已取消关机”，主界面恢复未启动状态。
- **⏱️ 延迟 5 分钟**：将计划关机时刻向后顺延 5 分钟，提醒窗口关闭，并在下一次关机提醒时再次弹窗。
- **⏱️ 延迟 10 分钟**：将计划关机时刻向后顺延 10 分钟。
- **⏱️ 延迟 30 / 60 分钟**：更长时间的延后，满足临时加时需求。
- **⚡ 立即关机**：若已收拾好工作准备离开，可直接一键立刻关机。

### 4. 开机自动启动与托盘静默运行
- **一键开机自启**：主界面一键勾选 `[√] 开机自动启动`，自动写入 Windows 用户启动注册表：
  `HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`
  无需管理员提升权限，安全无污染。
- **后台托盘守护**：
  - 点击窗口右上角 `[X]` 自动最小化至系统托盘，不中断后台守护任务。
  - 支持 `-tray` 启动参数。开机自启时静默启动至托盘，不弹出窗口打扰用户。
  - 托盘图标 Hover 显示当前剩余时间，右键菜单支持快速延迟、取消任务、查看状态与彻底退出。
- **单实例运行保护**：内置 Windows 命名互斥锁（Mutex），防止重复运行多个实例导致关机冲突。若已在运行，再次启动会自动唤醒并前置现有窗口。

## 📁 项目目录结构

```
win-auto-shutdown/
├── main.go               # 程序主入口、命令行参数解析、单实例互斥锁与生命周期
├── config.go             # 配置持久化模型 (保存于 %APPDATA%\WinAutoShutdown\config.json)
├── autostart.go          # Windows 注册表开机自启动管理
├── scheduler.go          # 关机任务核心调度器、线程安全状态机、延迟与关机执行
├── scheduler_test.go     # 自动化单元测试 (调度、倒计时、延迟、取消、注册表与配置验证)
├── main_window.go        # 主界面 GUI、控件交互、系统托盘与全局 1 秒心跳调度
├── reminder_dialog.go    # 醒目的置顶关机提醒弹窗与秒级倒计时交互
├── app.manifest          # Windows 应用程序清单 (Common Controls v6 现代视觉样式 & DPI 感知)
├── app.rc                # 资源描述文件 (绑定图标与清单)
├── rsrc.syso             # 编译生成的 Windows COFF 资源目标文件
├── app.ico               # 应用程序图标 (时钟/电源符号)
├── build.bat             # 一键自动构建脚本
└── win-auto-shutdown.exe # 编译完成的独立无黑框可执行程序 (~6.2MB)
```

## 🛠️ 编译与运行

### 环境要求
- Windows 10 / 11 (amd64)
- Go 1.20 或更高版本 (已在 Go 1.26.5 测试通过)
- MinGW-w64 gcc / windres (用于资源与清单编译)

### 快速一键构建
直接双击运行目录下的 `build.bat`，或者在 PowerShell 中执行：
```powershell
# 1. 编译 Windows 清单与图标资源
windres -i app.rc -o rsrc.syso -O coff

# 2. 编译为 Windows GUI 无控制台窗口的独立程序
go build -ldflags="-H windowsgui -s -w" -o win-auto-shutdown.exe .
```

### 运行单元测试
```powershell
go test -v .
```
测试用例覆盖定时关机、倒计时计算、5分钟/10分钟延迟精度、取消逻辑、提前提醒阈值触发、配置读写与注册表开机自启操作。

## 🖥️ 使用指南

1. **启动程序**：双击 `win-auto-shutdown.exe` 打开主界面。
2. **设定时间**：
   - 选择【指定时刻关机】，设置期望关机的小时与分钟（可点击快捷时刻），按需勾选【每天固定此时间关机】。
   - 或选择【倒计时关机】，设置倒计时间。
3. **设置提醒**：
   - 在【提前提醒】中输入或选择期望提前的分钟数（默认为 `5` 分钟）。
   - 勾选【提醒时播放警示音】。
4. **开启自启**：勾选【开机自动启动】，之后开机将直接在托盘静默运行。
5. **点击【启动定时关机】**：
   - 界面进入倒计时状态，剩余时间实时跳动。
   - 点击右上角关闭按钮，程序将收起至右下角系统托盘。
6. **提醒弹窗触发**：
   - 当距离关机仅剩设定的提前提醒时间（例如 5 分钟）时，屏幕正中央将弹出**置顶警告窗口**并播放提示音。
   - 您可以直接点击 **【取消关机】** 放弃本次关机，或点击 **【延迟 5 分钟】** / **【延迟 10 分钟】** / **【延迟 30 分钟】** 顺延关机时间。
